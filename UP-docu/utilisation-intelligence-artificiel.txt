UTILISATION DE L’INTELLIGENCE ARTIFICIELLE DANS LE PROJET

CONTEXTE

Dans le cadre de ce projet de site e-commerce "UP", nous avons utilisé des outils d’intelligence artificielle comme support d’apprentissage et d’aide au développement.

L’objectif n’était pas de laisser l’IA produire le projet à notre place, mais de l’utiliser comme un outil pour mieux comprendre certaines notions et progresser plus efficacement.

OUTILS UTILISÉS

- ChatGPT
- Codex

TYPES D’UTILISATION

1. Aide à la compréhension

L’IA nous a permis de :
- comprendre certaines notions techniques (API, requêtes HTTP, front-end / back-end)
- clarifier le fonctionnement de bibliothèques ou de concepts
- expliquer des erreurs ou des comportements inattendus dans le code

2. Aide à la structuration

Nous avons utilisé l’IA pour :
- organiser certaines parties du projet
- améliorer la lisibilité du code
- structurer les fichiers et la logique générale

3. Assistance ponctuelle au développement

L’IA a été utilisée pour :
- proposer des pistes de correction en cas de bug
- suggérer des méthodes ou des approches
- aider à écrire certaines portions de code

Chaque proposition a été relue, comprise et adaptée avant d’être intégrée au projet.

4. Aide pour la communication front ↔ back

L’IA a été particulièrement utile pour :
- comprendre comment envoyer des requêtes HTTP
- structurer les appels API (fetch / axios)
- gérer les réponses et erreurs côté front-end

LIMITES DE L’UTILISATION

L’utilisation de l’IA demande une réflexion et un encadrement précis :

- Il a fallu apprendre à bien formuler les demandes (prompt)
- Il est nécessaire de préciser les technologies, les contraintes et le contexte
- Il faut guider l’IA sur ce qu’elle doit faire et ce qu’elle doit éviter
- L’IA peut proposer du code incorrect ou non adapté au projet
- Elle ne comprend pas toujours l’ensemble du projet

Nous avons donc systématiquement :
- testé le code proposé
- corrigé les erreurs
- adapté les solutions à notre projet

APPORTS DE L’IA

L’utilisation de l’IA nous a permis :
- de gagner du temps
- d’apprendre de nouvelles technologies
- de mieux comprendre le fonctionnement d’un site web complet
- d’améliorer la qualité du projet

CONCLUSION

L’intelligence artificielle a été utilisée comme un outil d’aide, au même titre qu’une documentation.

Elle nous a permis de monter en compétence rapidement, tout en gardant un rôle actif dans la conception, la compréhension et le développement du projet.
